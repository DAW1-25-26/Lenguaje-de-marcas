Descripcion de CSS

CSS representa lasl siglas de Cascading Style Sheets, que podemos definir comom el lenguaje que nos permite controlar el aspecto visual de nuestro documento HTML

HTML y CSS se complementan para separar el contenido y su presentacion

Esta division nos aporta numerosas ventajas, puesto que, al ser independientes el contenido y el aspecto visual, para un mismo contenido podremos tener diferentes visualizacionesl. Esta caracteristica es fundamental para poder trabajar en distintos dispositivos.
